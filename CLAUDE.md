# asm-adlandirma — çalışma kuralları

- **Açık geliştirme:** her anlamlı gelişme aynı turda commit + `git push`. Bu repo herkese açık.
- Push öncesi: anahtar, e-posta, hesap/bakiye, kişisel bilgi yok. Anahtarlar yalnız `~/Desktop/evren.env`.
- Evren: düşünme kapalı varsayılan, toplam eşzamanlılık ≤16, günlük 15M token. Ayrıntı README.
- Platform API'de yalnız bu projeye ait işlemler; billing/transfer/withdraw/private-key uçlarına dokunma.
- Herkese açık yayın (Evren public veri seti, HF, sosyal medya) gönderi başına Emin onayı ister.
- Oturum sonunda `.taslak/x.md` dosyasına 1-2 X taslağı ekle (git dışı).
